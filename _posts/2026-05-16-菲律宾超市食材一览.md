## 一、主食类

| 食材 | 当地名称 | 特性 |
|------|---------|------|
| 大米 | Bigas / Sinandomeng、Dinorado、Jasmine | 菲律宾主食，Dinorado 颗粒细香、Sinandomeng 性价比高，Jasmine 香米软糯 |
| 糯米 | Malagkit | 用于煮糯米饭、做 suman、biko 等点心 |
| 干面条 | Pancit Canton / Bihon / Miki | Canton 是黄面（类似乌冬），Bihon 是细米粉，Miki 是新鲜碱水面 |
| 番薯 | Kamote | 天然带甜，可蒸可烤，替代糖分零食 |
| 木薯 | Kamoteng kahoy | 淀粉感强，需彻底煮熟 |
| 紫山药 | Ube | 天然紫色微甜，可做糊或代替糖做甜点 |

## 二、蔬菜类（全部不辣）

| 食材 | 当地名称 | 特性 |

| 辣木叶 | Malunggay | 名字带"辣"但完全不辣，营养极高，常加入汤里 |
| 佛手瓜 | Sayote | 口感清脆似冬瓜，煮熟温热吃最合适 |
| 苦瓜 | Ampalaya | 苦味强，孩子可少量 |
| 长茄子 | Talong | 紫色细长，烤后软糯 |
| 秋葵 | Okra | 黏液感重，蒸或煮 |

| 南瓜 | Kalabasa | 自带甜味，蒸煮都很糯 |

| 柚子 | Suha | 比国内沙田柚酸度略高 |
| 龙宫果 | Lansones | 一串串小果，清甜带微酸 |

## 八、奶制品（重点：全家喜欢热饮）

| 食材 | 当地名称 | 特性 |
|------|---------|------|
| 鲜牛奶 | Fresh milk（Magnolia、Selecta Moo） | 冷藏柜出售，**喝前请隔水加热或微波至温热** |
| 淡奶 | Evaporated milk（Alaska、Carnation） | **常温保存**！罐装无糖浓缩奶，加热水即变热牛奶，最适合本家口味 |
| 全脂奶粉 | Powdered milk（Bear Brand、Nido） | 常温储存，用热水冲即热奶，菲律宾家庭最常用 |
| 炼乳 | Condensed milk | **含糖量高，建议避开** |
| 奶酪 | Quesong Puti（白奶酪） | 软嫩偏咸，配热饭也行 |

> **建议组合**：用 Alaska Evap 淡奶 + 热水 + 一点 pandan，做温热奶饮；或用 Bear Brand 奶粉直接热水冲，避免冷藏奶的问题。

## 给本家的小贴士

1. **冷藏食材回温**：从超市冷柜买回来的牛奶、肉、豆腐，都先在室温回温 10–15 分钟，再加热烹饪或饮用。
2. **天然替糖**：成熟 Saba 香蕉、Kamote（紫薯/番薯）、熟透芒果、椰浆、Pandan，都能让甜点不加糖也好吃。
3. **暖身菜推荐**：Tinolang Manok（姜汤鸡）、Arroz Caldo（姜味鸡粥）、Ginisang Munggo（炒绿豆汤）—— 都是热乎、温补、不辣的国民菜。
4. **避辣提醒**：菲律宾辣味通常来自 Sili Labuyo（鸟眼椒），常用于 Bicol Express、Laing、Pinakurat 辣醋；只要避开这几样和带 "spicy" 字样的产品即可。
